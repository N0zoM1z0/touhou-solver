## Question And Problem Contract

The physical objective remains Sakuya/Remilia survival with hard no-Bomb
input. This audit asks a narrower question: when the retained Hard Stage-4A
live trace queried an empty published global kernel before contact, which
declared finite-model changes make that *same immutable query root* viable?

The audited root contains the capsule bytes and SHA-256, capsule source and
snapshot frames, context key, player query position, active native input,
current and capsule delay supports, spatial and temporal discretization,
horizon, and the retained projected hazard trajectories. The action set is the
existing 17-direction/focus no-Bomb set. The BASE recurrence is the existing
80-frame, eight-frame-layer robust viability recurrence. Short horizons,
current-query delay support, uncertainty removal, and finer lattices are
counterfactual diagnostics, not alternate live contracts.

The audit has no issue-time deadline because it is offline. It may publish
only completed finite results. Timeout, exception, unavailable query,
unvisited variant, or missing capsule is unresolved and cannot be called
empty. The live fallback, publication cadence, four-worker global service,
fresh local certificate, and hard no-Bomb behavior remain unchanged.

## Information And Physical Scope

**Observed:** each dossier root is content-addressed and records the exact
query observation used by the published controller. Replaying it therefore
answers the retained finite recurrence at that query without choosing a
hidden delay branch after seeing its outcome.

**Inferred:** physical histories with identical retained root fields are
equivalent only for this finite recurrence. They are not proved physically
control-equivalent because future ECL births, transforms, body state, pending
command history, frozen-manager episodes, and later sensing can differ.

**Conclusion:** even an exact solve answers a finite proxy. It does not prove
physical survival, global route feasibility, or causal blame for the later
contact. This is why the dossier uses orthogonal labels instead of one
overloaded `empty`.

**Observed — `SPATIAL_AMBIGUITY` (6/61):** BASE at 16 pixels is empty while at
least one same-root 8- or 4-pixel solve is viable. The legacy source label
called these coarse false empties. The dossier uses the narrower name because
finer finite-grid viability does not prove physical viability and uniform
full-field 4-pixel delivery is far outside the live budget.

**Observed — `SHORT_HORIZON_ONLY` (8/61):** at least one H=32/48/64 solve is
viable while H=80 is empty. A shorter horizon weakens the survival obligation;
it is an optimistic diagnostic, not a safety repair.

**Observed — `MODELED_LOSING_UNRESOLVED` (47/61):** no tested single-factor
counterfactual rescues the root. This is the dominant cohort, 77.0% of the
retained empty roots.

**Observed — `FUTURE_BIRTH_GAP` (7/61):** the later collision projectile slot
is absent from the source capsule. These seven overlap the primary
classifications and remain separate.

**Inferred:** adding a missing later hazard can remove viable states but cannot
make an empty kernel viable. A future-birth gap is therefore model-soundness
evidence, never an explanation for a false empty.

**Hypothesized:** later birth geometry may explain part of the physical
contact path, but the slot-delta audit does not establish the missing
projectile trajectory or causal effect.

## Five Contract Questions

1. **Which histories merge?** Histories with the same retained capsule and
   query fields merge for the finite recurrence. Future births, actuator
   history, and frozen-clock state can make them physically inequivalent.
2. **Are quantifiers causal?** The replay uses the retained robust recurrence
   and one immutable observation root. Diagnostic variants change a declared
   factor before solving. It does not maximize separately over a hidden exact
   delay after observing the outcome.
3. **What would an exact solve answer?** Only feasibility of the declared
   finite model for the declared horizon and terminal contract.
4. **What does the algorithm prove?** The native full induction completes the
   retained finite variants. Digest or field mismatch falsifies replay.
   Physical contact under a claimed winning witness, a missing hazard, or an
   observation-incompatible branch falsifies stronger interpretations.
5. **Can it be consumed before issue?** No. This is offline analysis. No
   result is placed on the live publication or input path.
